# Lumen Blue

NZXT Kraken Elite web integration face (640x640 round LCD). Blue recolor of the Lumen face from [Najibra/nzxtv2](https://github.com/Najibra/nzxtv2), which is free to use and modify.

Accent colors:
- Labels and units: `#4da3ff` (`--accent` in `styles.css`)
- Ring gradient: `#9ccbff` to `#3f8fe8` (`index.html`)
- Leading dot: `#d6e9ff`

To change the blue, edit those three places.
